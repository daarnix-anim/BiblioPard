# BiblioPard — 3D & Media Asset Library Extension
> **Версия**: `0.0.1`  
> **Совместимость**: Adobe After Effects 2024, 2025, 2026.2+ & Premiere Pro 2024+

**BiblioPard** — профессиональное расширение для каталогизации, интерактивного 3D-предпросмотра и моментального импорта ассетов в один клик для After Effects и Premiere Pro.

---

## 🌟 Ключевые возможности

### 1. 3D-модели (GLTF, GLB, OBJ)
- **Интерактивный WebGL вьювер (Three.js)**: вращение, панорамирование, зум, переключение фонов и сетки.
- **Импорт в 1 клик**: импортирует модель в проект After Effects, добавляет в активную композицию и переключает на нативный движок **Advanced 3D Renderer**.
- **Генератор 360° GIF**: авто-генерация кругового облета модели для предпросмотра при наведении (hover preview) в карточках библиотеки.

### 2. 3D PBR-Материалы (Shader Ball)
- **Авто-распознавание текстурных наборов**: Albedo/BaseColor, Roughness, Metalness, Normal, Height/Displacement, AO, Emission.
- **Shader Ball Viewport**: интерактивная сфера предпросмотра материалов с физически корректным шейдингом (`MeshPhysicalMaterial`) и HDR-отражениями.
- **Организованный импорт в AE**: создание структуры папок `Materials / [Имя_Материала]` в окне проекта.

### 3. Карты освещения (HDR, EXR)
- Предпросмотр панорам окружения на зеркальной тестовой сфере.
- **Создание Environment Light**: автоматическое создание слоя источника света окружения в After Effects и назначение текстуры.

### 4. Добавление ассетов прямо из After Effects
- Кнопка **«From AE»** считывает выделенные элементы в панели Project (`app.project.selection`) и мгновенно открывает мастер добавления ассета.

### 5. Авто-трекер папки (Auto-Watcher)
- Библиотека автоматически отслеживает добавление новых файлов в Проводнике Windows (`fs.watch`) и мгновенно обновляет витрину ассетов без перезагрузки.

### 6. Автообновление через GitHub
- Проверка новых релизов через GitHub Releases API.
- Уведомление о выходе новой версии и скачивание обновлений в один клик.

## 🚀 Быстрая установка (Windows)

1. Скачайте архив репозитория или склонируйте его:
   ```bash
   git clone https://github.com/Pard/BiblioPard.git
   ```
2. Запустите двойным кликом файл **`install.bat`**.
3. Запустите или перезапустите **After Effects**.
4. Откройте: **`Window` (Окно) ➔ `Extensions` (Расширения) ➔ `BiblioPard`**.

### Удаление расширения
- Для полного удаления расширения из After Effects и Premiere Pro запустите двойным кликом **`uninstall.bat`**.
- Ваши файлы библиотеки (3D модели, HDR, материалы) останутся нетронутыми.

## 🏷️ Публикация новых версий на GitHub

В репозиторий встроен **GitHub Actions CI/CD workflow** (`.github/workflows/release.yml`). Для выпуска новой версии:

1. Измените версию в `package.json` и `CSXS/manifest.xml` (например, `0.0.2`).
2. Закоммитьте изменения и поставьте git-тег:
   ```bash
   git commit -am "Release v0.0.2"
   git tag v0.0.2
   git push origin main --tags
   ```
3. GitHub Actions автоматически соберет проект, запакует `BiblioPard-v0.0.2.zip` и опубликует официальный релиз в разделе **Releases** на GitHub!
